# a spill

The mark is a lowercase `a` with a paint puddle, built from loaded brush strokes.

## Files

| File | Use |
|---|---|
| `a-spill.svg` | Painted master, ink and rose, drips and spatter |
| `a-spill-reversed.svg` | Painted master for dark grounds |
| `a-spill-mono.svg` | One colour |
| `a-spill-small.svg` | Simplified cut for 16 to 32 px |
| `a-spill-tile.svg` | Simplified tile for the tab icon |
| `a-spill-tile-512.png`, `-192.png` | Painted tile, light |
| `a-spill-tile-dark-512.png` | Painted tile, night |
| `a-spill-512.png`, `-32.png`, `-16.png` | Transparent mark |
| `favicon.ico` | 16, 32, 48 |

Large icons use the painted master. The 16 and 32 px cuts drop the drips, spatter and grain so the letter stays readable.
